# Remediation log

Every defect found while building and testing ScholarPlan: how it was found, its root cause, the fix, and the evidence that the fix works. Entries are in the order they were found. Where a test found a fault **in the test itself** rather than in the system, the entry says so. Those cases are recorded too, because each one clarified the intended behaviour.

| ID | Found by | Symptom | Root cause | Fix | Verified by |
|---|---|---|---|---|---|
| R1 | Environment setup | `uv python install 3.11` downloaded Python but failed with "Missing expected target directory for Python minor version link". | uv could not create the version-alias link on this Windows/OneDrive profile. | Created the virtual environment from the explicit interpreter path (`cpython-3.11.17`), keeping the Python version the Unit 6 design specifies. | `.venv` reports Python 3.11.17; all tests run on it. |
| R2 | Environment setup | The machine's global Git identity belonged to another person, so commits would have been misattributed (an academic-integrity risk for an individual submission). | The global config was shared from earlier group work on the same laptop. | Set a repository-local Git identity for the author, and authenticated the GitHub CLI to the author's own account. The global setting was left untouched. | `git log --format='%an'` shows only the author. |
| R3 | First end-to-end mock run | `FutureWarning: get_sentence_embedding_dimension has been renamed`. | sentence-transformers 6 renamed the API. | Compatibility shim that uses the new name when present (`embeddings.py`). | Warning gone in later runs. |
| R4 | First end-to-end mock run | Hugging Face "symlinks not supported" warning cluttered the demo logs. | Windows without Developer Mode cannot create symlinks; the cache still works. | `HF_HUB_DISABLE_SYMLINKS_WARNING=1` set before the import. | Warning gone. |
| R5 | Manual inspection of first report | Two different works both cited as "(Wang et al., 2024)", which is ambiguous under Harvard. | No author–year disambiguation. | `disambiguate_years()` adds 2024a/2024b, and the reference list is sorted by surname then year label. | `test_same_author_year_gets_letters`; re-run report shows 2024a/2024b. |
| R6 | Manual inspection of first report | arXiv references carried version suffixes (`2402.11651v2`). | The Atom `<id>` includes the version. | Strip `vN` and build a canonical `https://arxiv.org/abs/<id>` URL. | `test_arxiv_parse_recorded_response`. |
| R7 | Manual inspection of first report | Reference without a venue rendered as `'Title', Available at:`. | The punctuation was hard-coded around the venue. | Venue-aware punctuation in `harvard_reference()`. | `test_harvard_reference_format`; re-run report. |
| R8 | First live call to Groq | `HTTP 404 model_not_found` for `llama-3.3-70b-versatile`, the Critic model chosen in Unit 6. | The model is not offered to new free-tier accounts (confirmed with the `/models` endpoint on 11 Oct 2026). | Critic switched to `qwen/qwen3.8-27b`. A different model family from the generator preserves the design's independence argument. Added automatic substitution to `openai/gpt-oss-120b` if a model is withdrawn mid-run. | Manual Critic check (correctly rejected a fabricated "50% on all benchmarks" claim); `test_live_client_substitutes_withdrawn_model`. |
| R9 | Unit test `test_top_k_and_missing_abstract` | Expected 2 selected sources, got 1. | **Test-data fault:** the five synthetic abstracts were near-identical, so the Processor *correctly* removed them as near-duplicates (cosine ≥ 0.92) before top-k was applied. | Test data rewritten with distinct topics, with a comment explaining why. | Test passes; the failure was itself evidence that the dedup threshold works. |
| R10 | First live run (trace) | `openalex request failed: HTTP 429` for one subtask. The run continued on arXiv and Crossref (isolation worked), but evidence was lost. | The fixed 1.5 s back-off was shorter than OpenAlex's window, and requests were spaced only 0.2 s apart. | Honour the `Retry-After` header with exponential back-off, and space OpenAlex/Crossref requests 1 s apart. | `test_http_retries_transient_errors`; subsequent live runs. |
| R11 | Unit test `test_same_author_year_gets_letters` | Expected "et al.", got "(Wang and Z, 2023)". | **Test fault:** two-author works are correctly cited "A and B" under Harvard. | Test uses three-author works. | Test passes. |
| R12 | Functional tests (re-planning scenarios) | Scripted Planner replies were consumed by routine "issue subtask" steps before the failure the test wanted to force. | Test harness: scripted items were unconditional. | `ScriptedLLM` callables may return `None` to defer to the default policy, so each scenario forces exactly one path. | 11/11 functional tests pass. |
| R13 | Functional test `test_critic_rejection_triggers_reflexion_replanning` | Rejected claim text appeared in the report. | **Test fault, design nuance:** after re-planning, the same sentence was re-extracted from the same abstract and independently *verified* as a new claim with a new id. | Assertion now compares claim **ids**: no rejected claim id may appear in the report. | Test passes. |
| R14 | Trace review (mock run) | Mock Planner wrote "Coverage is sufficient" when zero subtasks were verified. | Misleading canned thought text in the mock. | Reworded to "No further subtask is worth pursuing". | Trace review. |
